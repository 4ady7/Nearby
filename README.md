# Between

A private space for two people. Leave a feeling, a photo, a question, or a memory without keeping a conversation going.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000. Create an account, open a space, and join from another browser with the code.

Data lives in `data/between.db`. Uploads live in `data/uploads/`. Neither is committed.

```bash
npm run build
npm start
npm run qa
```

`npm run qa` expects the app on http://127.0.0.1:3000.
